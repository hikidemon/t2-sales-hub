# T2 SALES HUB — Статус проекта

## Общие сведения

- **Версия:** 0.0.0 (Alpha)
- **Рабочая директория:** `D:\allprj\t2`
- **Stack:** React 18 + TypeScript + Vite + TailwindCSS + Express + pnpm monorepo
- **Node.js:** v24.22.0 · **pnpm:** 12.4.2

## Текущий этап

**Этап 5: авторизация через портал ABC T2, ролевой доступ, обезличенные
таблицы на Google Диске с автообновлением.**

Реализовано и проверено на фейковом портале ABC T2. Ожидается от
пользователя: доступ к порталу ABC T2 и OAuth-токен Google для загрузки
таблиц на Диск.

### Правила бренда, зафиксированные в системе

- Основные цвета — 90–100 % поверхности; маджента — акцент, не заливка.
- Дополнительный цвет — не более 20 % макета.
- Шрифт Halvar Breitschrift используется только в ExtraBold.
- Бент-система — основной метод компоновки, модули разных пропорций.

Подробно — `docs/design/DESIGN_SYSTEM.md`.

### Проверки, которые выполнить не удалось

- **Инструмент `browser_exec`** — профиль Chrome пользователя занят работающим браузером.
  Проверки выполнены отдельным headless-инстансом (порт 9224, профиль во временной
  папке). Пользовательский браузер не затрагивался.
- **Визуальная оценка скриншота** — инструмента анализа изображений в этой сессии нет.
  Композиция проверена программно: геометрия блоков, вычисленные цвета, тени, шрифты
  (`scripts/t2-style-probe.mjs`, `scripts/t2-layout-probe.mjs`).
- **Сервисный аккаунт ABC T2 и 1С** — клиент в `auth.t2.ru` ещё не выпущен; 1С ждёт
  согласования схемы. Честно показывают состояние «не настроена».
- **Сайт abc.t2.ru из терминала недоступен** (SSL-сбой) — исследован через
  headless Chrome; конфигурация провайдера взята из его discovery-документа.
- **Вход через T2 ID недоступен части сотрудников** (продавцы салонов t2,
  сотрудники T2) — на странице входа портала есть прямое предупреждение.

### Что осталось

1. **Клиент в `auth.t2.ru`** — свой client ID, client secret и разрешённый
   redirect URI. Код готов и проверен на фейковом портале; в `.env` вписываются
   четыре значения (`ABC_T2_CLIENT_ID`, `ABC_T2_CLIENT_SECRET`,
   `ABC_T2_REDIRECT_URI`, `ABC_T2_SCOPES`).
2. **Триггер автообновления** — по одной минуте на каждую таблицу в Apps Script.
3. **Схема данных 1С** — формат выгрузки и подтверждённые правила расчёта.
4. **Шрифты T2** — лицензия на Halvar Breitschrift и Rooftop (заготовка `@font-face` готова).
5. **Переключатель темы** — светлая/тёмная, тёмная палитра уже готова.
6. **Массовое назначение тестов** и отдельная страница куратора со статистикой.
7. **Доставка уведомлений** в email/Telegram.
8. **Разделы продукта** — «Доход», «Результаты», «Рейтинг», «Профиль».
9. **Вход по логину-паролю** для части сотрудников, которым T2 ID недоступен.

### Следующий этап

Получить клиент в `auth.t2.ru` → вписать четыре значения в `.env` → включить
`AUTH_REQUIRED=true` → подключить `AbcT2Adapter` по контракту
`ExternalSystemAdapter` для чтения данных о продажах. Страницы и
бизнес-логика при этом не меняются: профиль и роль уже приходят из портала.
