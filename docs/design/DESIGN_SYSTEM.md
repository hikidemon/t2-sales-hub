# T2 Sales Hub — Дизайн-система

Документ описывает визуальный язык проекта: он воспроизводит официальный стиль T2
и добавляет два слоя — **neo** (жёсткие бент-блоки) и **glassmorphism** (полупрозрачные
поверхности с размытием).

Все значения взяты из **официального style guide** (brand.t2.ru) и проверены на живом
сайте `t2.ru` извлечением вычисленных стилей через headless Chrome.

---

## 1. Источник истины

| Что            | Источник                    | Как проверено                                        |
| -------------- | --------------------------- | ---------------------------------------------------- |

| Типографика    | brand.t2.ru → «Типографика» | Текст style guide + `font-family` с t2.ru            |

`scripts/extract-brand-page.mjs` (текст и свотчи style guide),
`scripts/read-page-text.mjs` (текст страницы).

## 2. Цвет

### Основная палитра (90–100 % материалов)

| Роль              | Значение  | Где применяется                        |
| ----------------- | --------- | -------------------------------------- |
| Маджента (акцент) | `#FF3495` | Акценты, выделения, брендовые элементы |
| Чёрный / ink      | `#1F2229` | Текст, тёмные бент-блоки               |
| Белый             | `#FFFFFF` | Фон карточек, текст на тёмном          |

Правило бренда: **маджента — акцент, а не заливка больших площадей и не цвет текста.**
В интерфейсе она занимает единицы процентов и всегда работает парой с чёрным/белым.

### Дополнительная палитра (не более 20 % макета)

| Роль         | Значение  | Назначение по гайду                         |
| ------------ | --------- | ------------------------------------------- |
| Салатовый    | `#A7FC00` | Заливка кнопок и плиток под иконки          |
| Электрик-блю | `#00BFFF` | Альтернатива мадженте, когда она уже занята |
| Синий        | `#1E40AF` | Только для цифровых коммуникаций            |

### Нейтральная шкала (ink)

`#F5F5F7` (фон) → `#1F2229` (текст) → `#6B717F` (приглушённый) → `#0D0E12` (тёмная тема).

### Токены

`packages/ui/src/tokens/colors.ts` → CSS-переменные в `packages/ui/src/styles/global.css`
→ классы Tailwind в `packages/config/tailwind/preset.js`.

Цвета хранятся как «R G B»-каналы, чтобы работали модификаторы прозрачности
(`bg-background-card/80`).

### Темы

- **Светлая — по умолчанию.** T2 построен на белом фоне; так выглядит официальный сайт.
- **Тёмная** доступна через `[data-theme='dark']` с теми же акцентами.

Переключение задаётся в `apps/web/src/app/providers/index.tsx` (`DEFAULT_THEME`).

## 4. Бент-система

Основной метод компоновки по гайду: информация раскладывается по модулям разного
пропорционального соотношения, а не по равномерной сетке одинаковых карточек.

| Параметр             | Формула  | Значение в макете |
| -------------------- | -------- | ----------------- |
| Внешнее поле         | X × 0.02 | `--bento-margin`  |
| Зазор между модулями | X × 0.01 | `--bento-gutter`  |
| Скругление бента     | X × 0.04 | `--bento-radius`  |
| Внутренний отступ    | X × 0.04 | `--bento-padding` |

На странице это выражено тем, что блоки имеют **разные ширины и высоты**:
головный бент занимает 2 колонки из 3, график — 2 из 3, рейтинг и прогноз — по одной.

### Радиусы

8 px (кнопки, мелкие элементы) · 12 px · 16 px (карточки) · 32 px (крупные плитки).

### Тени

**T2 elevation** — мягкая тень с обратной подсветкой, снята с реальных элементов t2.ru:

```css
box-shadow:
  0 2px 16px 0 rgb(31 34 41 / 0.06),
  0 -10px 22px 0 rgb(31 34 41 / 0.03);
```

## 5. Neo — жёсткие бент-блоки

Слой «neo» добавляет к бент-системе плоский, физический характер: чёткая рамка и
смещённая тень без размытия.

```css
.neo-block {
  border: 2px solid #1f2229;
  box-shadow: 4px 4px 0 0 #1f2229;
}
.neo-block-brand {
  border: 2px solid #1f2229;
  box-shadow: 4px 4px 0 0 #ff3495;
}
.neo-block-lime {
  border: 2px solid #1f2229;
  box-shadow: 4px 4px 0 0 #a7fc00;
}
```

При нажатии смещение схлопывается — блок «уходит» в поверхность.

Где применяется: главный доходный блок (neo-brand), ближайшая цель (neo + лаймовая
рамка), назначенные тесты (neo), навигация в мобильной нижней панели.

## 6. Glassmorphism

Слой «glass» — полупрозрачная поверхность с размытием подложки. Чтобы стекло читалось
как стекло, а не как полупрозрачный прямоугольник, у слоя есть **верхняя подсветка**.

```css
.glass-surface {
  background-color: rgb(var(--color-glass-surface) / var(--color-glass-alpha));
  backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgb(var(--color-glass-border) / var(--color-glass-border-alpha));
  box-shadow:
    inset 0 1px 0 0 rgb(var(--color-glass-highlight) / var(--color-glass-highlight-alpha)),
    0 8px 32px 0 rgb(31 34 41 / 0.1);
}
```

| Параметр    | Светлая тема                | Тёмная тема              |
| ----------- | --------------------------- | ------------------------ |
| Поверхность | `rgba(255,255,255,0.62)`    | `rgba(31,34,41,0.72)`    |
| Размытие    | `blur(20px) saturate(180%)` | то же                    |
| Граница     | `rgba(31,34,41,0.08)`       | `rgba(250,250,250,0.10)` |
| Подсветка   | `rgba(255,255,255,0.9)`     | `rgba(250,250,250,0.16)` |

Где применяется: рейтинг, прогноз, статус источника данных, уведомления, состав
дохода, шапка профиля, верхняя и нижняя панели оболочки.

**Glass используется умеренно** — примерно треть поверхностей. Он не заменяет все
карточки: neo-блоки и обычные поверхности дают contrast.

## 7. Компоненты UI-kit

`packages/ui/src/components/`: `avatar`, `badge`, `button`, `card`, `chart/LineChart`,
`icon`, `progress`, `separator`, `toast`.

| Компонент   | Особенности T2                                                                                                      |
| ----------- | ------------------------------------------------------------------------------------------------------------------- |
| `Button`    | `primary` — лайм с чёрным текстом (по гайду), `accent` — маджента, `secondary` — электрик-блю, `neo` — жёсткая тень |
| `Badge`     | Варианты `brand`, `lime`, `electric` по палитре бренда                                                              |
| `Card`      | Варианты `default`, `glass`, `neo`, `elevated`, `outlined`                                                          |
| `Icon`      | 30 иконок, единый механизм SVG-путей, без эмодзи и сторонних библиотек                                              |
| `LineChart` | Адаптивный SVG без зависимостей, тултип, точки не искажаются                                                        |
| `Toast`     | Тосты с цветовым кодом серьёзности и текстовым описанием                                                            |

Правила: типизированные пропсы; состояния `hover` / `focus` / `disabled` / `isLoading`;
единый контур фокуса из `--color-border-focus`; `prefers-reduced-motion: reduce`
отключает анимации.

## 8. Иконографика

Принцип построения — из гайда: иконка строится на модульной сетке, линии одной
толщины, скруглённые окончания.

Реализация: единый реестр SVG-путей в `packages/ui/src/components/icon/Icon.tsx`,
типизированный `IconName`. Новая иконка добавляется в `paths` и в `IconName`.

---

## 9. Доступность

- Контраст текста к фону — не ниже 4.5:1 (проверяется по токенам ink).
- Фокус с клавиатуры виден на всех интерактивных элементах.
- Цвет никогда не единственный носитель смысла: у тостов и бейджей есть текст,
  у статусов — подпись.
- `prefers-reduced-motion: reduce` отключает анимации и переходы.
- Иконки без текста помечены `aria-hidden`; смысловые — получают `aria-label`.
- Минимальная подпись — 10 px, интерактивные элементы — не менее 36 px.

| 640–1023  | Две колонки в KPI, нижняя навигация                            |
| 1024–1279 | Сайдбар, бент 2+1, 4 KPI в ряд                                 |

768×1024, 1280×800, 1440×900 — горизонтальной прокрутки и переполнений нет.
