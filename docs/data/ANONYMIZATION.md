# Обезличивание таблиц и автообновление данных

Исходные рабочие книги содержат реальные персональные данные: фамилии
продавцов в названиях листов и в графах «Фамилия СП». В приложение они
попадать не должны — ни в код, ни на Google Диск.

## Как это сделано

Обезличивание идёт **на уровне XLSX-архива**, а не через openpyxl.
Причина: openpyxl при сохранении выбрасывает графики, картинки и часть
форматирования, а в рабочих книгах есть и то и другое (в «Планы продаж
НР» — 215 листов, 216 графических частей).

Правится только текст:

| Часть архива           | Что меняется                                               |
| ---------------------- | ---------------------------------------------------------- |
| `xl/sharedStrings.xml` | текстовые значения ячеек                                   |
| `xl/worksheets/*.xml`  | инлайн-строки и ссылки на переименованные листы в формулах |
| `xl/workbook.xml`      | названия листов-ФИО                                        |

Остальное переносится байт-в-байт: формулы, стили, графики, валидации,
защита листов, комментарии, VML.

## Формулы остаются нетронутыми

Формула меняется в одном-единственном случае: если лист переименован,
ссылка на него в формуле обновляется. Само выражение не трогается.

Проверка после каждого файла:

```
Копия  Планы продаж НР.xlsx              формул 12134 → 12134  (сохранены)
г. Новосибирск, пр. Карла Маркса, д.7.xlsx формул  9448 →  9448  (сохранены)
Единый Калькулятор Combo .xlsx           формул   167 →   167  (сохранены)
```

## Что считается персональными данными

- **Фамилия** — по окончанию (`-ов`, `-ева`, `-ин`, `-ина`, `-ук`,
  `-енко`, `-ич`, `-ых`, `-ский`…) и по справочнику имён. Так
  «Мотивация Наставников» остаётся разделом правил, а «Елезова
  Ксения» переименовывается.
- **Полное имя** — фамилия + имя из справочника (+ отчество по
  окончанию `-ич`/`-вна`).
- **Телефон** — маскируется до `+7 *** *** 1234`.
- **Электронная почта** — `i***@t2.ru`.
- **Название листа-ФИО** — заменяется на «Продавец 001».

Всё, что не попало под правила, остаётся как есть: названия торговых
точек, адреса, номенклатура, правила мотивации.

## Псевдонимы

Сопоставление «настоящее имя → псевдоним» общее для всех книг, поэтому
связи между таблицами сохраняются: один и тот же продавец в разных
файлах получает один и тот же `EMP-xxx`.

Карта лежит в `.data/anonymization-map.json`, который:

- в `.gitignore`;
- **не загружается на Google Диск**;
- не попадает в приложение.

## Запуск

```bash
uv venv .venv-sheets --python 3.13
uv pip install --python .venv-sheets/Scripts/python.exe openpyxl

./.venv-sheets/Scripts/python.exe scripts/anonymize_sources.py \
    --input-dir "C:/Users/nikyu/AppData/Local/hermes/attachments" \
    --output-dir "build/anonymized" \
    --reset
```

`--reset` забывает прежнюю карту и начинает нумерацию заново.
Отчёт — `build/anonymized/anonymization-report.json`.

## Загрузка на Google Диск

```bash
uv pip install --python .venv-sheets/Scripts/python.exe \
    google-api-python-client google-auth google-auth-oauthlib

./.venv-sheets/Scripts/python.exe scripts/upload_to_drive.py --interactive
```

Скрипт:

1. создаёт папку `T2 Sales Hub / Обезличенные`;
2. загружает туда все обезличенные книги;
3. печатает ссылки на файлы.

Дальше — включить «Доступ по ссылке» (кто угодно с ссылкой — просмотр)
для каждой таблицы и вписать идентификаторы в `.env`:

```env
DATA_SOURCE=google-sheets
GOOGLE_SHEETS_SPREADSHEET_ID=<id таблицы «Общие»>
GOOGLE_SHEETS_REPORT_GID=515868842
```

## Автообновление по ссылке

Приложение читает таблицу по ссылке через `gviz` и обновляет данные
каждые `SYNC_INTERVAL_MS` (по умолчанию 5 минут) плюс по требованию
администратора.

Чтобы формулы в таблице пересчитывались, в неё добавляется триггер
Google Apps Script — `scripts/google-sheets-refresh-trigger.gs`:

1. «Расширения» → «Apps Script» в обезличенной таблице;
2. вставить файл, сохранить;
3. «Триггеры» → «Добавить триггер»: функция `refreshTotals`,
   источник — по времени, интервал — 5 минут;
4. один раз запустить `installTrigger` вручную и выдать разрешения.

Триггер пересчитывает формулы и пишет отметку времени в лист
«Служебный» — видно, что данные свежие. Формулы и данные он не
изменяет.
