# T2 Sales Hub — Правила расчёта мотивации

Правила извлечены из `НР_ Обновленная мотивация Т2 15.10.2026.xlsx` (4 листа) и из формул
листа «ЗП» торговой точки. **Это официальный регламент, извлечённый из исходных таблиц,
а не реконструкция.** Где правило удалось подтвердить формулой — приведена формула;
где это утверждение в тексте — помечено как «текст регламента».

Условные обозначения:
**✓ подтверждено формулой** · **◐ подтверждено текстом и структурой** · **? требует уточнения**

## 0. Иерархия и структура выплаты

| Уровень        | Что входит                                                                                 | Источник правила        |
| -------------- | ------------------------------------------------------------------------------------------ | ----------------------- |
| Окладная часть | Часы × ставка                                                                              | «Мотивация» стр. 13–16  |
| Бонусная часть | Блоки GI, Приоритетные акции, Цифровые сервисы, Фиксированные услуги, Оборудование, Прочие | «Мотивация» стр. 18–143 |
| Итог           | ОКЛАД + бонусы × коэффициенты                                                              | «ЗП» стр. 14–22         |

Сроки выплат (текст регламента, стр. 3–4):

- **Аванс** — на карту, 30-е число текущего месяца и 15-е число следующего за отчётным.
- **Зарплата** — в расчётке, 30-е число месяца, следующего за отчётным.

### Окладная часть

| Параметр             | Значение                          | Статус |
| -------------------- | --------------------------------- | ------ |
| Норма часов на месяц | **165 часов (21 смена)**          | ◐      |
| Ставка               | **104 ₽/час**                     | ◐      |
| Ставка переработки   | **120 ₽/час** (сверх нормы часов) | ◐      |

Оклад считается по количеству отработанных часов за месяц; часы берутся из листа «график»
(столбец C = `SUM(D:AH)` — сумма часов по дням месяца).

### Статусы специалистов по продажам (стр. 7)

`Старший` · `Основной` · `Стажер`.

**Мотивация стажёра:** оклад = мотивации СП; бонусная часть = мотивации СП (стр. 10–11).
Фактически стажёр получает мотивацию СП без изменений — отдельных тарифов нет.

## 1. Блок GI (стр. 18–40)

Выплачивается за GI с учётом прохождения проверки СМЭВ.

Оси тарифной сетки:

- **Строки** — тариф (Мой разговор, Мой Онлайн, Мой Онлайн +, Black, ИДУ, Premium, Игровой,
  Везде онлайн, Классический +MIXX, Я онлайн, Хватит, Партнер М_ИМ, Партнер М,

  Замена сим, Подарки).
- **Столбцы** — два зеркальных блока: **«ФТП не выполнено»** (C–G) и **«ФТП выполнено»** (H–L).

## 4. Блок «Цифровые сервисы» (стр. 73–85)

**Оборудование РТК** — % бонуса СП от суммы продаж АО РТК (от суммы зачёта в план по АО):

| Выполнение плана | %                               |
| ---------------- | ------------------------------- |
| Менее 100 %      | **10 %**                        |
| От 100 до 120 %  | **13 %**                        |
| Выше 120 %       | **не оплачиваются** (стоп-план) |

**Подписочные сервисы**: план ≥80 % — **20 %**; план <80 % — **10 %**.
В зачёт идут Wink, Лицей, Комбозащита, подписки MIXX 3/6/12.

**Антивирус PRO 32**: план ≥80 % — **30 %**; план <80 % — **15 %**.

Условия (стр. 79):

- План оборудования РТК выставляется в рублях на ТТ; в зачёт идут все продажи АО РТК без учёта
  скидки (колонки, приставки, камеры, подписки ВН).
- Камеры с повышенным КФ в зачёт плана идут с учётом повышенного КФ выполнения; в расчёт ЗП
  идут по РЦ, без учёта скидок.
- В зачёт выполнения плана по ВН попадает только **активная** продажа: камера привязана к
  учётной записи ≥20 дней и активна на дату отчёта (период наблюдения = месяц продажи + 20 дней);
  подписка ВН привязана к учётной записи.

## 10. Блок ВМР (лист «ВМР»)

Операторский мониторинг — мотивация за каждую анкету:

| Результат анкет   | Сумма       |
| ----------------- | ----------- |
| 101 % и выше      | **2000 ₽**  |
| От 80 % до 100 %  | **1500 ₽**  |
| От 77 % до 79,9 % | **0 ₽**     |
| От 0 % до 76,9 %  | **−2000 ₽** |

Условия:

- Премия за положительную анкету выплачивается только при выполнении показателя на ТТ.
- Демотивация за неудовлетворительную анкету — только при невыполнении показателя на ТТ.
- При отсутствии предложения «Новая сим + ШПД РТК» или «Новая сим + АО РТК» демотивация
  за каждую анкету **−500 ₽ независимо от показателя**.
- Если по итогам отчётного месяца ТТ закрыла план по ШПД РТК — штраф за отсутствие РТК
  в анкете обнуляется.

**Внутренний ВМР с 25.03.2026:** анкета на 80 % и выше — **300 ₽**; ниже 79,9 % — **−400 ₽**.

## 13. Как это применяется в таблице «ЗП» (формулы)

Лист «ЗП» торговой точки применяет правила регламента. Формулы, воспроизведённые из исходника:

**Бонус за показатель (столбец «Бонус» листа «Лист_продаж»):**

```excel
=IF('ЗП'!$Z$11<1,
   IF('ЗП'!$V$11<0.95,
      IF(AND('ЗП'!$AD$11>=1, 'ЗП'!$W$8/'ЗП'!$V$8>=7%, 'Видеомониторинг'!$D$13>=80), AS5, AO5),
      IF('ЗП'!$V$11<1, AP5, IF('ЗП'!$V$11<1.1, AQ5, AR5))),
   IF('ЗП'!$V$11<0.95,
      IF(AND('ЗП'!$AD$11>=1, 'ЗП'!$W$8/'ЗП'!$V$8>=7%, 'Видеомониторинг'!$D$13>=80), AW5, AT5),
      IF('ЗП'!$V$11<1, AU5, IF('ЗП'!$V$11<1.1, AV5, AW5))))
```

Ключевые ссылки:

- `'ЗП'!$V$11` — **процент выполнения плана** (стр. 11) — задаёт диапазон тарифа
  (<95 % / <100 % / <110 %).
- `'ЗП'!$Z$11` — **прогноз плана** (стр. 10) — <1 → «ФТП не выполнено», ≥1 → «ФТП выполнено».
- `'ЗП'!$AD$11` — выполнение плана конверсии ≥1.
- `'ЗП'!$W$8/'ЗП'!$V$8 >= 7 %` — доля Приоритетных акций (план/факт) ≥7 %.
- `'Видеомониторинг'!$D$13 >= 80` — ВМР ≥80 % (внешний показатель, не из этих файлов).
- `AS5..AW5` — адреса ячеек тарифной сетки листа «Лист_продаж».

**Сводные показатели листа «ЗП»:**

```excel
План на день       = ROUNDUP(План / (Дней в месяце - Отработано дней), 0)
План на сотрудника = План на день / 2
Факт               = SUM('Лист_продаж'!C545:AG545)      # своя строка на показатель
Не хватает до плана= План - Факт
Прогноз плана      = (Факт / Отработано дней * Дней в месяце) / План
Процент выполнения = Факт / План
```

**Константы в «ЗП»:** `Отработано дней` = `DAY(TODAY())-1`; `Дней в месяце` — из «Общие»;
понижающий коэффициент при невыполнении GI на 100 % = **0,95**;
понижающий коэффициент ЧС Кредитование (менее 5 заявок по ТТ) = **0,95**.

## 15. Как это ложится на архитектуру проекта

```
packages/core/src/
├── calculation/
│   ├── demoRules.ts        ← демо-правила Этапа 2 (упрощённые, помечены)
│   └── motivationRules.ts  ← НОВЫЙ: правила, извлечённые из таблиц (production)
├── domain/dashboard.ts      ← модели
└── format/format.ts         ← форматтеры
```

**Принцип:** `motivationRules.ts` содержит **чистые функции**, вычисляющие бонус по правилам
регламента, и принимает на вход факт и пороги из таблиц. Сетки тарифов (например GI) выносятся
в типизированные структуры данных — их можно либо загружать из Google-таблицы «Мотивация T2»,
либо зафиксировать в коде как константы с указанием источника.

Каждое правило сопровождается ссылкой на источник (`лист`, `ячейки`, `строка`) — так, чтобы
изменение регламента можно было отследить.
